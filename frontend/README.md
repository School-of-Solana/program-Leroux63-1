# Roundpot

Minimal Solana dApp built with:

- **Anchor** (on-chain program)
- **Next.js 15** (frontend)
- **Wallet Adapter** (Phantom / Solflare)
- **@coral-xyz/anchor** client
- **Tailwind** + shadcn/ui

This project provides a basic interface to interact with the **Roundpot Anchor program**, including:

- Initialize pool  
- Join pool  
- Activate pool  
- Contribute  
- Settle current cycle  
- Withdraw collateral  

Everything is wired to run **on Devnet**.
